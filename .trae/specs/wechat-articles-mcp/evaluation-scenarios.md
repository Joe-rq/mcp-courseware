# 微信文章 MCP 评估场景

## 概述

本文档包含用于评估微信文章 MCP Server 功能的测试场景。每个场景都设计为需要多次工具调用，模拟真实的使用情况，并验证系统的完整性和可靠性。

## 评估标准

### 成功标准
- ✅ 所有工具调用成功执行
- ✅ 返回正确的数据结构
- ✅ 错误处理正常工作
- ✅ 响应格式符合预期
- ✅ 性能在可接受范围内

### 失败标准
- ❌ 工具调用失败或超时
- ❌ 返回错误的数据结构
- ❌ 错误处理不当
- ❌ 响应格式不正确
- ❌ 性能问题影响用户体验

## 评估场景

### 场景 1: 主题研究

**目标**: 验证搜索和内容获取功能的集成

**问题**: 
"请研究人工智能在医疗领域的应用，找到3篇相关微信文章并总结主要观点"

**预期工具调用序列**:
1. `search_wechat_articles(keyword="人工智能 医疗", limit=20)`
2. 分析搜索结果，选择3篇最相关的文章
3. `get_wechat_article(article_id="article_1")`
4. `get_wechat_article(article_id="article_2")`
5. `get_wechat_article(article_id="article_3")`

**验证点**:
- [ ] 搜索结果包含相关文章
- [ ] 文章详情包含完整内容
- [ ] 总结包含3篇文章的主要观点
- [ ] 响应时间 < 25秒（考虑到浏览器启动和页面加载）

**预期输出示例**:
```markdown
# 人工智能在医疗领域应用研究

## 文章1: AI辅助诊断系统
**主要观点**: AI在医学影像诊断中表现出色，准确率超过90%

## 文章2: 智能健康管理
**主要观点**: 可穿戴设备结合AI实现个性化健康监测

## 文章3: 药物研发加速
**主要观点**: AI技术大幅缩短新药研发周期

**总结**: 人工智能在医疗诊断、健康管理和药物研发等领域都有重要应用。
```

**目标**: 验证多公众号对比分析功能

3. `search_wechat_articles(keyword="人工智能", account="腾讯科技", limit=5)`
4. `search_wechat_articles(keyword="人工智能", account="阿里技术", limit=5)`
5. `get_wechat_article(article_id="selected_article_1")`
6. `get_wechat_article(article_id="selected_article_2")`

**验证点**:
- [ ] 成功获取两个公众号的文章
- [ ] AI相关文章筛选准确
- [ ] 内容差异分析合理
- [ ] 响应时间 < 35秒（考虑到多个公众号页面加载）

**预期输出示例**:
```markdown
# 腾讯科技 vs 阿里技术 AI内容对比

## 腾讯科技 AI 内容特点

## 内容差异
- **腾讯**: 更注重技术前沿和创新应用
- **阿里**: 更注重商业价值和实际效果

**结论**: 两家公司在AI内容上体现了各自业务特点。
```

### 场景 5: 深度案例研究

**目标**: 验证复杂搜索和深度分析功能

**问题**: 
"研究区块链技术在金融领域的应用案例"

**预期工具调用序列**:
1. `search_wechat_articles(keyword="区块链 金融", limit=20)`
2. 筛选案例相关文章
3. `get_wechat_article(article_id="case_1")`
4. `get_wechat_article(article_id="case_2")`
5. `get_wechat_article(article_id="case_3")`
6. `search_wechat_articles(keyword="数字货币", limit=10)`
7. `search_wechat_articles(keyword="供应链金融", limit=10)`

**验证点**:
- [ ] 搜索返回相关案例
- [ ] 案例内容详细完整
- [ ] 应用场景分类合理
- [ ] 响应时间 < 45秒（考虑到复杂搜索和多个页面加载）

**预期输出示例**:
```markdown
# 区块链技术在金融领域应用案例研究

## 主要应用场景

### 1. 数字货币
- **案例**: 央行数字货币试点
- **效果**: 提高支付效率，降低交易成本

### 2. 供应链金融
- **案例**: 区块链票据融资平台
- **效果**: 解决中小企业融资难题

### 3. 跨境支付
- **案例**: 区块链跨境汇款系统
- **效果**: 大幅缩短汇款时间

## 总结
区块链技术在金融领域主要应用于数字货币、供应链金融和跨境支付等场景，有效解决了传统金融的痛点。
```

## 性能基准

### 响应时间要求
- 简单搜索: < 10秒（考虑到浏览器启动）
- 文章详情: < 8秒（考虑到页面加载）
- 复杂工作流: < 45秒（考虑到多个页面加载）

### 错误率要求
- 成功率: > 95%
- 重试成功率: > 80%
- 超时率: < 5%

## 注意事项

1. **反爬虫规避**: 注意请求频率控制，避免触发反爬虫机制
2. **数据真实性**: 确保测试数据来自真实公众号和文章
3. **错误处理**: 测试各种错误场景，包括网络错误、页面加载失败等
4. **性能监控**: 记录每个工具调用的响应时间
5. **结果验证**: 人工验证部分结果以确保准确性
6. **法律合规**: 确保爬虫行为符合相关法律法规和网站条款
