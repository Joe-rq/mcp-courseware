# 微信文章 MCP 工具设计

## 1. 工具选择与优先级

### 1.1 工具设计原则
基于微信文章获取的实际情况，我们采用 Playwright + Python 模拟浏览器方案：
- **技术优势**：完全模拟真实浏览器行为，支持JavaScript动态内容加载
- **成本优势**：开源免费，无需支付API调用费用
- **控制优势**：完全控制数据获取流程，避免第三方API依赖
- **合规性**：合理控制请求频率，遵守网站使用条款

### 1.2 技术架构调整
**核心变更**：
- 从第三方API调用改为直接网页爬取
- 使用 Playwright 处理动态内容加载
- 实现智能等待和错误重试机制
- 支持代理配置和用户代理轮换

### 1.2 工具列表及优先级

| 工具名称 | 类别 | 优先级 | 状态 | 描述 |
|---------|------|--------|------|------|
| `search_wechat_articles` | 搜索 | 高 | 计划中 | 根据关键词搜索微信文章 |
| `get_wechat_article` | 内容 | 高 | 计划中 | 获取单篇文章的详细内容 |
| `list_wechat_articles_by_account` | 搜索 | 中 | 计划中 | 按公众号获取文章列表 |
| `get_trending_wechat_articles` | 分析 | 中 | 计划中 | 获取热门微信文章 |

## 2. 工具详细设计

### 2.1 Tool 1: search_wechat_articles

**目的**：让Agent能够根据关键词搜索微信文章

**技术实现**：
- 通过搜索引擎或微信搜一搜获取文章链接
- 使用 Playwright 模拟浏览器访问搜索结果
- 提取文章标题、描述、公众号、URL等信息

**输入参数**：
- `keyword` (必填)：搜索关键词
- `limit` (可选，默认10)：返回结果数量
- `search_source` (可选，默认"weixin_sogou")：搜索源
- `format` (可选，默认"json")：响应格式
- `detail` (可选，默认"concise")：详细程度

**输出格式**：
- 文章列表，包含标题、描述、公众号、URL等

**价值**：
- 快速查找相关微信文章
- 支持研究和内容分析

### 2.2 Tool 2: get_wechat_article

**目的**：获取单篇微信文章的详细内容

**技术实现**：
- 使用 Playwright 访问文章URL
- 等待页面完全加载（网络空闲状态）
- 提取文章标题、正文、公众号信息
- 智能处理图片和富文本内容

**输入参数**：
- `article_url` (必填)：文章URL
- `include_content` (可选，默认true)：是否包含文章正文
- `format` (可选，默认"markdown")：响应格式
- `timeout` (可选，默认10000)：超时时间(毫秒)

**输出格式**：
- 文章标题、作者、发布时间、正文内容等

**价值**：
- 深入阅读和分析单篇文章
- 提取关键信息

### 2.3 Tool 3: list_wechat_articles_by_account

**目的**：按公众号获取文章列表

**技术实现**：
- 通过公众号主页或历史消息页面获取文章列表
- 使用 Playwright 模拟滚动加载获取更多文章
- 提取文章标题、发布时间、阅读量等信息

**输入参数**：
- `account_name` (必填)：公众号名称
- `limit` (可选，默认10)：返回结果数量
- `time_range` (可选)：时间范围筛选
- `include_metrics` (可选，默认false)：是否包含阅读量等指标

**输出格式**：
- 指定公众号的最新文章列表

**价值**：
- 跟踪特定公众号的内容
- 内容聚合和分析

### 2.4 Tool 4: get_trending_wechat_articles

**目的**：获取热门微信文章

**输入参数**：
- `category` (可选)：文章分类
- `limit` (可选，默认10)：返回结果数量

**输出格式**：
- 热门文章列表，包含阅读量等指标

**价值**：
- 发现热门话题和趋势
- 内容推荐

## 3. 工具协同工作流

### 3.1 典型工作流

**工作流1：研究特定主题**
1. `search_wechat_articles(keyword="人工智能")` → 获取相关文章列表
2. 从结果中选择感兴趣的文章ID
3. `get_wechat_article(article_id="...")` → 获取详细内容
4. 分析文章内容

**工作流2：跟踪公众号内容**
1. `list_wechat_articles_by_account(account_name="腾讯科技")` → 获取最新文章
2. 筛选感兴趣的文章
3. `get_wechat_article(article_id="...")` → 深入阅读

**工作流3：发现热门内容**
1. `get_trending_wechat_articles(category="科技")` → 获取热门文章
2. 分析热门话题趋势

## 4. 技术实现策略

### 4.1 Playwright 集成方案
**核心配置**：
- 无头浏览器模式：节省资源，提高性能
- 用户代理轮换：模拟不同浏览器，降低被检测风险
- 智能等待机制：确保内容完全加载
- 代理服务器支持：支持IP轮换

### 4.2 请求管理
**频率控制**：
- 请求间隔：1-3秒随机延迟
- 并发控制：单线程处理，避免过度请求
- 错误重试：网络错误自动重试2-3次

### 4.3 数据提取优化
**内容提取**：
- CSS选择器定位关键元素
- 文本清理和格式化
- 图片链接提取
- 富文本内容处理

## 5. Agent 体验优化

### 5.1 响应格式
- **简洁模式**：基本信息，适合快速浏览
- **详细模式**：完整信息，适合深入分析
- **JSON格式**：结构化数据，适合程序处理
- **Markdown格式**：人类可读，适合展示

### 5.2 错误处理
- 清晰的错误信息
- 具体的建议操作
- 重试机制

### 5.3 性能考虑
- 响应时间控制在2-5秒内
- 支持分页和限制
- 字符限制：25,000 tokens
